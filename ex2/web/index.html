Dùng cho app bạn build/deploy thường xuyên — bấm 1 nút là tải bản mới nhất từ URL và cài thẳng vào thiết bị đang kết nối. Hỗ trợ link GitHub blob (tự chuyển sang link tải gốc) và link tải trực tiếp (GitHub Releases...).

Kéo-thả file .apk / .xapk / .apks / .apkm vào đây, hoặc bấm để chọn file

"Ẩn đã chọn": file đã cài trên xe → ẩn thật trên thiết bị (bật lại ở tab "Danh sách package"); file chưa cài → chỉ ẩn khỏi danh sách này, bấm "Hiện lại" là thấy lại ngay.
